# Hariharan Navaratnaraja - Portfolio

A modern, responsive portfolio website showcasing my skills, projects, and experience as a Full Stack Developer.

## 🚀 Features

- Responsive design
- Modern UI with animations
- Interactive 3D elements
- Contact form
- Project showcase
- Skills section
- About me section

## 🛠️ Technologies Used

- React
- Tailwind CSS
- Framer Motion
- Three.js
- EmailJS
- Vite

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/HariShockings/my-portfolio.git
```

2. Install dependencies:
```bash
cd my-portfolio
npm install
```

3. Run the development server:
```bash
npm run dev
```
